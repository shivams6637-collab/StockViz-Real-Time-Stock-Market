# Contributing to StockViz

## Development Guidelines

1. Review the README and documentation in `docs/`.
2. Create a separate branch for your changes.
3. Keep changes focused and preserve existing license notices.
4. Never commit credentials, `.env` files, database contents, or personal information.
5. Add or update tests when changing behavior.
6. Run relevant checks before submitting a pull request.

## Pull Requests

Describe the change, testing performed, known limitations, and any configuration or migration requirements. Include screenshots for significant UI changes where useful.
